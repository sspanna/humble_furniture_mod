## What this is

A Minecraft Fabric mod (mod id: `humble_furniture`) targeting Minecraft 26.2 / Java 25, built with Fabric Loom. It is currently the stock Fabric example-mod template (`ModInitializer` entrypoint + one example mixin) — no real gameplay content has been added yet.

## Commands

Requires [SDKMAN](https://sdkman.io); `.sdkmanrc` pins the JDK (`java=25.0.4-tem`).

```
sdk env install       # one-time: install pinned JDK
./gradlew runClient   # launch a dev Minecraft client with the mod loaded
./gradlew runServer   # launch a dev server
./gradlew build       # compile + package; jar output in build/libs/
```

There is no test suite currently configured. CI (`.github/workflows/build.yml`) just runs `./gradlew build` on JDK 25 (Microsoft distribution) for every push/PR.

## Architecture

- `src/main/java/dev/tee3/humble_furniture/Humble_furniture.java` — the mod's `ModInitializer` entrypoint (registered in `fabric.mod.json` under `entrypoints.main`). Holds `MOD_ID` and a helper `id(String path)` that builds a namespaced `Identifier` (`humble_furniture:<path>`) — use this for any resource/registry identifiers instead of constructing `Identifier`s by hand.
- `src/main/java/dev/tee3/humble_furniture/mixin/` — Mixin classes, registered in `src/main/resources/humble_furniture.mixins.json` (`package` + `mixins` list). Compatibility level is `JAVA_25`; `requireAnnotations: true` and `defaultRequire: 1` mean every injector must declare an explicit `@At`/require, and unmatched mixins fail the build rather than silently no-opping.
- `src/main/resources/fabric.mod.json` — mod metadata, entrypoints, mixin config registration, and dependency version constraints (fabricloader, minecraft, java, fabric-api). When bumping Minecraft/loader/API versions, update both this file's `depends` block and `gradle.properties`.
- `gradle.properties` — single source of truth for Minecraft/loader/Loom/Fabric API versions and the mod `version`/`group`.
- Assets/data (textures, models, blockstates, lang files, recipes, loot tables, etc.) go under `src/main/resources/assets/humble_furniture/` and `src/main/resources/data/humble_furniture/` following standard Fabric/Minecraft resource-pack and data-pack layout — none exist yet beyond `assets/humble_furniture/icon.png`.
- `run/` is the Gradle-managed dev environment (game files, saves, logs, config) — gitignored, regenerated by the `run*` tasks.
